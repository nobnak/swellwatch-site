SwellWatch プライバシーポリシー

最終更新日: 2026年11月17日

本プライバシーポリシーは、Wear OS アプリケーション「SwellWatch」（以下「本アプリ」）における利用者情報の取り扱いについて定めるものです。

1. 取得および送信する情報

  • 位置情報（概算・正確な位置情報 / ACCESS_COARSE_LOCATION・ACCESS_FINE_LOCATION）
    利用者が「現在地 (GPS)」モードを選択し位置情報権限を許可した場合に限り、現在地の緯度・経度を取得します。バックグラウンドでの常時位置追跡は行いません。
  • 利用者が指定・検索した地点情報
    ポイント検索（音声入力・キーボード入力）で入力された地名、または手動指定された緯度・経度。

2. 利用目的

取得した情報は、以下の目的にのみ使用します。

  • 指定地点または現在地における波浪（うねり）・風向風速・潮位・水温・気温予報の取得および表示
  • 海岸線（沖の向き）の自動推定
  • 地点名による候補検索

3. 外部サービスへのデータ送信

予報データおよび地点検索結果を取得するため、以下の外部気象・地図 API へ緯度・経度または検索キーワードを HTTPS 通信により送信します。

  • Open-Meteo（Marine / Elevation / Geocoding API）
    https://open-meteo.com/en/terms
  • MET Norway（Locationforecast 2.0 API）
    https://api.met.no/doc/TermsOfService

4. データの保存および第三者提供

  • 本アプリは開発者自身のサーバーへ利用者の位置情報や個人情報を送信・保存しません。
  • アプリの設定値および最新の予報キャッシュは、利用者の端末内（Android DataStore）にのみ保存され、アプリのアンインストールにより削除されます。
  • 広告配信 SDK やアクセス解析ツールは組み込んでおらず、第三者へのデータ販売・共有も行いません。

5. 権限の取り消し

利用者は、Wear OS 端末の「設定」＞「アプリ」＞「SwellWatch」＞「権限」からいつでも位置情報の許可を取り消すことができます。位置情報を許可しない場合でも、登録ポイントや緯度・経度指定モードにより本アプリを利用できます。
