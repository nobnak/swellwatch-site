SwellWatch

Wear OS 向け サーフィン波情報・コンパスアプリ

SwellWatch は、サーフポイントのうねり（1次・2次）、風向・風速、潮位カーブ、コンディションスコア、ウェットスーツ目安を手元の Wear OS ウォッチで直感的に確認できるスタンドアロンアプリです。

プライバシーポリシーを見る

主な機能

  • コンパス画面：海岸線（沖の向き）と海陸アーク、うねり・風の方向ベクトルを北固定／ウォッチ連動で表示
  • 詳細オーバーレイ：画面タップで数値詳細（うねり1・2、風、潮位・潮回り、水温・気温・ウェット目安）を確認
  • 時系列予報：左スワイプで +3h〜+12h のスコア・波高・風向推移を確認
  • 地点設定：GPS 現在地、登録サーフポイント、音声検索、緯度・経度指定、海岸線方位の自動推定に対応
  • Wear OS タイル＆コンプリケーション対応

データ出典

  • 波浪・潮位・標高・ジオコーディング：Open-Meteo
  • 気象予報：MET Norway
